## [1.0.0] - 2024-XX-XX

### Added
- Initial release of React Compiler Marker CLI
- Check React Compiler optimization status for components
- Support for .tsx, .jsx, .ts, .js files
- Multiple output formats (text, compact, JSON)
- CLI options for filtering and verbosity
- Error reporting with reasons and suggestions
- CI mode with exit codes
